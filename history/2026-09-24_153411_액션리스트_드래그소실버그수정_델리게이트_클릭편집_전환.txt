[결과 요약 / Summary of Results]
1. 드래그 앤 드롭 시 노드 소실 버그 완벽 해결:
   - 기존 Qt의 `setDragDropMode(InternalMove)`가 드롭 시 내부적으로 원본 행을 삭제(removeRows)하면서 셀 위젯 및 아이템들이 사라지는 문제가 발생했던 원인을 규명.
   - 안전한 커스텀 드래그 앤 드롭(`QDrag` + `QMimeData` + `sig_row_reordered`) 방식으로 전면 개편하여 내부 행 삭제 충돌을 차단하고, 시나리오 모델 재배열 후 `_refresh_actions_table()`로 모든 노드 및 셀 데이터가 깨끗하게 보존되도록 수정.
   - 메인 윈도우 시나리오 목록(`DraggableScenarioTableWidget`)에도 동일한 안전한 드래그 방식을 적용.

2. 평상시 깔끔한 텍스트 출력 & 클릭 시 인라인 편집 전환 (QStyledItemDelegate 구현):
   - `ActionColumnDelegate`를 개발하여 `오프셋`, `대기`, `로그` 열에 적용:
     * 평상시: 입력칸/콤보박스가 노출되지 않고, '액션 유형' 열처럼 가독성 높은 깔끔한 텍스트(예: '약', '0.5s', '로그 문구')로 출력.
     * 클릭/더블클릭 시: 해당 셀을 누르는 순간 즉시 편집 컨트롤(오프셋 콤보박스 / 대기 스핀박스 / 로그 텍스트필드)이 열려 바로 수정 가능.
     * 편집 완료 시: 엔터 또는 다른 곳 클릭 시 편집 컨트롤이 닫히며 깔끔한 텍스트 상태로 복귀.

3. 대기 시간 편집 시 상하 화살표(스핀 버튼) 제거:
   - 대기 시간 에디터에 `setButtonSymbols(QAbstractSpinBox.NoButtons)`를 적용하여 상하 화살표를 완전히 없애고 키보드로 원하는 숫자를 직접 입력할 수 있도록 개선.

4. 테스트 및 규칙 준수:
   - `tests/test_inspector_action_table.py`에 델리게이트 렌더링, 화살표 없는 대기시간 직접 입력, 드래그 앤 드롭 후 노드 보존 테스트 등 6개 케이스 모두 100% 통과 확인.
   - `core/version.py`의 `__version__`을 `260924.1533`으로 갱신.
