2. 액션조건 및 시퀀스 관련 명칭 정리 & 액션 시퀀스 노드화
   - 액션(Action): 액션 목록에 있는 개별 조작 단위 (클릭, 드래그, 키, 대기 등 1개 단위)
   - 액션 시퀀스(Action Sequence): 여러 액션을 순서대로 모아둔 재사용 가능한 한 묶음 (모듈화 단위)
   - 인식 조건(Recognition Condition): 화면/픽셀/색상 판정 조건
   - 시나리오(Scenario): 인식 조건 + 액션 시퀀스를 연결한 실행 단위
   - 액션 시퀀스 모듈화: 인식 조건 설정 후 기존에 만들어져 있는 액션 시퀀스를 연결(링크)하거나 시나리오 전용 액션으로 분리 가능

[결과 요약 / Summary of Results]
1. 액션 시퀀스(ActionSequence) 데이터 모델 및 모듈화 구조 구현
   - `core/models.py`:
     - `ActionSequence` 데이터클래스 정의 (id, name, description, actions, last_action_image_path 등)

     - `Project`에 `action_sequences` 목록 및 `find_action_sequence`, `add_action_sequence`, `delete_action_sequence` 구현
     - 시퀀스 삭제 시 참조 중인 시나리오의 sequence_id 자동 안전 해제 처리
     - JSON 직렬화/역직렬화(to_dict, from_dict) 완벽 지원
   - `core/runner.py`:
     - `_execute_actions` 및 루프 노드 실행 시 `scenario.get_effective_actions(project)`를 호출하여 연결된 공용 액션 시퀀스를 순차 실행 및 오버레이 시각화 연동
2. 액션 시퀀스 관리 다이얼로그 (ActionSequenceManagerDialog) 구현
   - `ui/action_sequence_manager_dialog.py`:
     - 등록된 모든 액션 시퀀스 목록 표시 (ID, 시퀀스명, 액션 수, 액션 요약, 참조 시나리오 목록)
     - 새 시퀀스 생성, 이름 변경, 복제, 삭제, 즉시 시퀀스 선택 기능 지원
3. 인스펙터 액션 시퀀스 UI 명칭 정리 및 모듈 연결 연동
   - `ui/inspector_widget.py`:
     - 카드 명칭 정리: "✋ 액션 시퀀스 (Action Sequence - 실행 동작)"
     - 상단에 시퀀스 연결 콤보박스 및 관리 버튼군 추가:
       • `[🔗 연결 시퀀스: ComboBox]` ("(시나리오 전용 액션)" vs "🔗 [시퀀스명] (N개 액션)")
       • `[💾 시퀀스로 등록...]`: 현재 액션 목록을 새 공용 액션 시퀀스 모듈로 등록 및 연결
       • `[🔓 연결 해제]`: 공용 시퀀스 링크를 해제하고 현재 시나리오 전용 독립 액션으로 복제
       • `[⚙️ 시퀀스 관리...]`: 시퀀스 매니저 모달 창 호출
     - 상태 안내 라벨: 공용 시퀀스 연결 상태 vs 시나리오 전용 액션 상태를 시각적으로 명확히 안내
     - 액션 추가/수정/삭제/이동/녹화/좌표지정/테스트 실행 시 활성 액션 리스트(`_get_active_actions_list()`)와 완벽 동기화
4. 항상 위 팝업 플레이바 (PopupPlayBar) 구현

     - 접기/펼치기(▲/▼) 토글 지원
     - 시나리오 퀵 프리셋 섹션:
       • 등록된 시나리오별 동적 칩 버튼 제공 (클릭 시 해당 시나리오부터 원클릭 즉시 실행)
