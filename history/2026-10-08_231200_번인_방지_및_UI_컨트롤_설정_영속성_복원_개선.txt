[결과 요약 / Summary of Results]
1. 번인 방지 설정(모니터 번인 방지 체크 여부, 모드 1/2 선택, 전환 주기 분) 미기억 버그 원인 분석 및 해결
   - 원인: MainWindow.__init__ 초기화 단계에서 UI 컴포넌트가 생성(_init_ui)되기 전에 _load_app_config()가 호출되어 위젯이 미존재(hasattr=False) 상태로 설정 로드가 무시되고, 이후 _init_ui()에서 기본값(False, 모드 1, 5분)으로 하드코딩 덮어쓰기됨. 또한 창 이동이나 종료 시 미체크 기본값(False)으로 config 파일이 덮어쓰여지는 구조적 문제 발생.
   - 해결:
     * _apply_ui_config() 메서드를 신설하여 _init_ui() 및 도크 레이아웃 초기화 직후 설정 파일(_cached_config)의 번인 방지 설정(anti_burn_enabled, anti_burn_mode, anti_burn_interval_min)을 위젯과 AntiBurnInOverlay 백엔드에 안전하게 복원(시그널 중복 발화 방지 blockSignals 적용).
     * _save_app_config() 시 위젯이 실제 존재할 때만 config를 갱신하도록 방어 코드를 적용하여 로드된 설정값의 의도치 않은 소실을 방지.

2. 다른 UI 기능 전수 검토 및 마지막 설정 영속성(Persistence) 확대 적용

     * action_overlay_enabled를 config에 저장/복원하도록 추가하고 토글 시 즉시 저장 연결.
   - 전역 플로팅 정지 (chk_floating_stop):
     * floating_stop_enabled를 config에 저장/복원하도록 추가.
     * 체크박스 토글 시 floating_stop 위젯의 실시간 show/hide 및 설정 저장 연동.
     * 매크로 실행(_on_start_execution) 시 플로팅 정지 옵션 활성화 상태이면 자동으로 플로팅 정지 바를 띄우도록 연동.
   - 코드 자동 리로드 (chk_hot_reload):
     * hot_reload_enabled를 config에 저장/복원하고 토글 시 즉시 저장 연결.
   - 로그 창 자동 스크롤 (chk_autoscroll):
