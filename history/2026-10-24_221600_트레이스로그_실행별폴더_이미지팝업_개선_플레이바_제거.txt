[1. 작업 배경 및 요구사항]
1) 트레이스 로그 폴더 생성 규칙 개선:
   - 각 시나리오 실행 시작(시나리오 실행 세션)마다 고유한 새 폴더(scenario_{프로젝트명}_{timestamp})를 생성.
   - 루프 회차마다 디렉터리가 파편화되거나 첫 로그 시 불필요한 분할 디렉터리가 생기던 문제 해결.
   - 1회 시나리오 실행 세션 내의 모든 루프와 스텝의 스크린샷이 해당 실행 폴더에 온전히 순서대로(#0001, #0002...) 보존.
2) 스크린샷 이미지 팝업 UI 개선:
   - 로그의 스크린샷을 클릭해 열린 이미지 크게 보기 창을 일일이 '닫기' 버튼을 누르지 않아도, 화면 아무 곳이나(이미지 영역, 배경, 메인 창 등) 클릭하면 즉시 자동 닫힘 처리.
   - 이미지 팝업 상단에 해당 스크린샷 파일이 저장되어 있는 폴더를 Windows 탐색기로 바로 열고 파일을 강조 표시해 주는 '📁 폴더 열기' 버튼 추가.
3) 플레이바 기능 제거:
   - 메인 윈도우 상단 툴바의 '🎮 플레이바 (F4)' 토글 버튼 및 F4 단축키 제거.
   - 백그라운드 PopupPlayBar 인스턴스 생성, 동기화 및 컨트롤러(playback_controller, config_lifecycle, table_controller, target_manager) 연동 코드 완전 제거.

[2. 주요 수정 내역]
1) core/trace_logger.py
   - `start_scenario_execution(scenario_name: Optional[str]) -> str` 메서드 추가:
     * 시나리오 실행 시 `scenario_{name}_{YYYYMMDD_HHMMSS}` 형식의 독립 폴더 생성.
     * 동일 초 내 중복 실행 시 `_1`, `_2` 접미사 충돌 방지 로직 적용.
   - `capture_screenshot_if_eligible`:
     * 폴더 미설정 상태에서 캡처 시 fallback으로 `start_scenario_execution()` 호출.

2) core/runner.py
   - `WorkflowRunner.run()`:
     * 실행 시작 시점에 즉시 `self.trace_logger.start_scenario_execution(self.project.name)`을 호출하여 실행 세션 전용 디렉터리 확정.
     * 루프 반복문(`while self._is_running:`) 내부에서 매 루프마다 `start_loop`를 호출하여 폴더를 파편화하던 로직 제거 (`current_loop_index`만 갱신).

3) ui/image_preview_dialog.py
   - `ImagePreviewDialog`:
     * '📁 폴더 열기' 버튼(`btn_open_folder`) 및 힌트 라벨(`lbl_hint: (아무 곳이나 클릭하면 닫힙니다)`) 추가.
     * `_open_folder()`: Windows 탐색기를 실행하여 해당 스크린샷 파일을 선택(`explorer /select,"{path}"`)하거나 상위 폴더 열기.
     * `QApplication.instance().installEventFilter(self)` 및 `mousePressEvent` 구현:
       - '📁 폴더 열기' 버튼 클릭이나 스크롤바 조작 외에 이미지, 배경, 대화상자, 앱 내 다른 영역 클릭 시 즉시 `self.accept()` 호출되어 대화상자 자동 닫힘.
       - QWindow 대상 이벤트 전달 시 `isAncestorOf`에 QWindow가 인자로 넘어가 발생하던 TypeError 방지: `event.globalPos()`의 버튼 바운딩 박스 판정 및 `isinstance(obj, QWidget)` 방어 로직 적용.
