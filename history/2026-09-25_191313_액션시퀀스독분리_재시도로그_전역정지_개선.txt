2. 조건 인식 - 재시도 때 로그에 재시도 출력.

[결과 요약 / Summary of Results]
1. 액션 시퀀스 창과 인식 조건 창 분리 및 도킹 레이아웃 자유화:
   - 기존의 단일 인스펙터 독(dock_inspector) 내부에 수직 스플리터로 함께 묶여 있던 인식 조건 패널과 액션 시퀀스 패널을 각각 독립적인 QDockWidget(`dock_inspector`: '인식 조건 / 분기', `dock_actions`: '액션 시퀀스')으로 분리 구현.
   - `InspectorWidget`을 조건 패널(ConditionPanelWidget)과 액션 패널(ActionPanelWidget)의 2개 서브위젯 구조로 모듈화하고, 시나리오 선택, 편집, 실시간 테스트, 저장/취소 시 양 패널이 완벽하게 동기화되도록 연동.
   - 사용자가 두 창을 독립적으로 이동, 분리 플로팅, 탭 결합(Tabified), 또는 나란히 배치(Side-by-Side)할 수 있도록 지원.
   - 메인 툴바의 레이아웃 프리셋 콤보박스에 "인식 조건 / 액션 나란히 (Side-by-Side)" 신규 프리셋 추가 및 메뉴바 [창/패널]에 액션 시퀀스 토글 메뉴 연동.

2. 조건 인식 재시도 시 실시간 진행 로그 출력:
   - `core/runner.py`의 `evaluate` 함수 내 조건 불일치 시 재시도 대기 루프에서, 현재 시도 횟수, 최대 허용 횟수, 다음 검사까지의 대기 시간을 실시간 로그로 발행하도록 개선.
   - 출력 예: "⏳ [#1] '시나리오명' 조건 불일치 - 재시도 대기 (1/3회, 0.5초 후 재검사)..."
   - UI 로그 패널 및 러너 시그널을 통해 사용자가 매 주기마다 대기 및 재검사 진행 상태를 명확히 확인 가능.

3. 전역 작동하는 시나리오 정지 시스템 구현:
   - Windows API `GetAsyncKeyState`를 폴링하는 경량 백그라운드 QThread `GlobalHotkeyListener`(`core/global_hotkey.py`) 신설.
   - FGOA 창이 비활성 상태이거나 다른 앱(게임 클라이언트 등)에 포커스가 가 있는 상태에서도 키보드 `F6` 또는 `Pause/Break` 키를 누르면 즉시 시나리오 실행이 긴급 정지되도록 구현.
   - 최상위 고정(Qt.WindowStaysOnTopHint | Qt.FramelessWindowHint) 플로팅 긴급 정지 위젯 `GlobalFloatingStopWidget`(`ui/floating_stop_widget.py`) 신설:
     * 시나리오 실행(F5) 시 화면 우상단에 작고 직관적인 빨간색 플로팅 바("🛑 긴급 정지 (F6)")가 자동 표시되며, 언제든 마우스로 클릭하여 즉시 정지 가능.
     * 마우스 드래그로 화면 원하는 곳 어디로나 자유롭게 위치 이동 가능.
     * 실행 완료 또는 정지 시 자동으로 숨김 처리되며, 하단 상태바의 '긴급 정지 팝업' 체크박스로 항시 켜기/끄기 설정 지원.
   - 스레드 안전성: `MainWindow` 파괴 시 및 프로세스 종료 시 `GlobalHotkeyListener`의 안전한 리소스 해제(atexit, destroyed 핸들러, QObject 계층 분리)를 적용하여 스레드 파괴 예외 완전 방지.

4. 품질 검증 및 버전 갱신:
   - 신규 단위 테스트 `tests/test_dock_split_retry_log_and_global_stop.py` 5개 케이스 통과.
   - 전체 1,138개 테스트 스위트 100% 통과 (exit code 0).
   - `core/version.py` 버전 `260925.1913`으로 갱신 완료.
