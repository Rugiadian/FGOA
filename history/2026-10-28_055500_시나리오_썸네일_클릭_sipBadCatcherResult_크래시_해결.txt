[작업 내용] 시나리오 썸네일 클릭 시 발생하는 'TypeError: invalid argument to sipBadCatcherResult()' 크래시 원인 분석 및 완전 해결

1. 문제 증상 및 원인 분석
   - 증상: 시나리오 테이블 목록의 레퍼런스 이미지 썸네일을 마우스로 클릭할 때 간헐적 또는 즉시 프로그램이 비정상 종료(Crash)됨.
   - 오류 로그:
     Error Type: TypeError
     Error Message: invalid argument to sipBadCatcherResult()
     Stack Trace: TypeError: invalid argument to sipBadCatcherResult()
   - 원인:
     1) `ui/main_window_parts/table_controller.py`의 라인 455에서 썸네일 라벨의 Qt 가상 메서드인 `mousePressEvent`에 인라인 람다(`lbl_thumb.mousePressEvent = lambda e, p=abs_ref, s=scen: (show_image_preview(...) if e.button() == Qt.LeftButton else None)`)를 할당하여 동적 몽키패칭을 수행함.
     2) C++ Qt의 `QLabel::mousePressEvent(QMouseEvent*)` 메서드는 반환 타입이 `void`(`None`)여야 함.
     3) 그러나 헬퍼 함수 `show_image_preview`가 생성된 다이얼로그 객체(`dlg`)를 반환하였고, 람다가 이 객체를 반환하게 됨.
     4) PyQt의 SIP 바인딩 레이어가 `void` C++ 함수에 반환된 Python 객체 타입을 검증하는 과정에서 타입 불일치로 `sipBadCatcherResult`를 호출함.
     5) 인스턴스에 동적 할당된 람다는 바운드 메서드(`PyMethod`)가 아닌 일반 함수(`function`)이므로, SIP 내부의 `PyMethod_Check()` 검사가 실패하여 상세 에러 메시지를 생성하지 못하고 `TypeError: invalid argument to sipBadCatcherResult()` 예외를 발생시키며 크래시를 유발함.

2. 구현 및 해결 내용
   - `ui/clickable_thumbnail.py`:
     - Qt 가상 함수를 몽키패칭하지 않고 정식으로 오버라이드하여 `clicked = pyqtSignal()`을 발행하는 재사용 가능한 `ClickableLabel(QLabel)` 클래스 정의.
     - `mousePressEvent`에서 좌클릭 감지 시 `self.clicked.emit()`을 안전하게 호출하고 `super().mousePressEvent(event)`를 통해 `None`을 정상 반환.
     - 기존 `ClickableThumbnailLabel`도 `ClickableLabel`을 상속받도록 정리.
   - `ui/main_window_parts/table_controller.py`:
     - 썸네일 라벨 생성 시 `lbl_thumb = ClickableLabel()`을 사용하도록 수정.
     - 위험한 `mousePressEvent = lambda ...` 몽키패칭을 제거하고, Qt 정식 시그널 연결 방식(`lbl_thumb.clicked.connect(...)`)으로 전환. Qt 시그널/슬롯 레이어는 슬롯 함수의 반환값을 안전하게 무시하므로 SIP 타입 변환 오류가 근본적으로 차단됨.
   - `ui/image_preview_dialog.py`:
     - `show_image_preview` 헬퍼 함수가 다이얼로그 객체 대신 명시적으로 `None`을 반환하도록 수정하여 다른 위치에서 호출 시 반환값 누수로 인한 부작용 원천 방지.
     - `eventFilter` 내에서 다이얼로그가 비활성화/숨김 상태(`not self.isVisible()`)일 경우 즉시 필터를 해제(`_remove_filter()`)하고 반환하도록 방어 로직 강화.
     - `hideEvent`에서도 `_remove_filter()`가 호출되도록 정리.
   - `ui/action_overlay.py` & `ui/widgets/dynamic_table.py`:
     - `nativeEvent`의 `eventType` 바이트 스트링 및 문자열 비교 호환성 강화 (`b"windows_generic_MSG"`).
     - `sizeHint` 반환값의 정수(`int`) 형변환 보장.
