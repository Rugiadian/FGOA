   - 원인 1: 시스템 PATH에 `git.exe` 바이너리 부재 (GitHub Desktop의 `git.cmd`만 PATH에 등록되어 있어, Unity Hub Electron 프로세스에서 `execFile('git')` 호출 실패로 "Git is not installed or not available in PATH" 발생 및 VCS 브랜치 조회 비활성화).
   - 원인 2: Unity Hub 설정 파일(`source-control-disconnected.json`)에 GitHub 및 GitLab이 연결 해제(차단) 상태로 등록되어 있음.
   - 원인 3: Git LFS 바이너리 부재.
   - 조치:
     - GitHub Desktop 내장 Git 바이너리를 가리키는 디렉터리 정션 `C:\Users\demo_\AppData\Local\GitHubDesktop\current-git` 생성.
     - 사용자 환경변수 `PATH`에 `C:\Users\demo_\AppData\Local\GitHubDesktop\current-git\cmd` 영구 등록 및 환경 브로드캐스트(`WM_SETTINGCHANGE`) 완료.
     - `git-lfs.exe` 하드링크를 `cmd` 디렉터리에 추가하여 Git LFS 지원 활성화.
     - `%APPDATA%\UnityHub\source-control-disconnected.json`의 차단 목록 초기화 (`{"providers":[]}`).
     - Unity Hub 재시작 후 로그에서 Git 바이너리 누락 오류가 완전히 해소됨을 검증.
