# FGOA (화면 인식 스마트 윈도우 오토 툴)

> **실행 조건을 화면의 정보를 읽어서 판단하는 윈도우 오토 입력 툴**  
> [색상 인식(Eye) ➔ 조건 판단(Brain) ➔ 액션 실행(Hand)]을 유기적인 시나리오 워크플로우로 구현합니다.

---

## ✨ 주요 특징 및 아키텍처

### 1. 🎯 선택창 상대 좌표 (Coordinate Pivot)
- 전체 해상도(절대 좌표)가 아닌 **선택한 창의 안쪽 클라이언트 영역(Client Area, 좌상단 0,0)**을 기준으로 동작합니다.
- 창의 위치가 화면 어디로 이동하든 상대 좌표를 기반으로 오차 없이 정확한 색상 감지 및 클릭을 수행합니다.
- 상단 툴바에서 열려 있는 창 목록을 검색하여 손쉽게 타겟 창을 지정할 수 있습니다.

### 2. 👁️ 포인트 읽기 - 컬러 피커 프리셋 (Eye)
- **단일 포인트 (Point Mode)**: 화면 특정 위치를 클릭하여 RGB 색상 값을 실시간 추출 및 저장.
- **선 모양 연속 포인트 (Line Mode)**: 시작점부터 끝점까지 드래그하여 지정한 개수(2~30개)의 포인트를 균등 분할 생성.
- **레퍼런스 이미지 연동**:
  - 📁 이미지 파일 불러오기
  - 📸 **현재 타겟 창 즉시 캡처하여 레퍼런스로 등록**
  - 📋 클립보드 이미지 붙여넣기 (`Ctrl+V`)
  - **해상도 가이드 & 클리핑**: 타겟 앱 해상도보다 큰 이미지가 등록되어도 좌상단(0,0)을 기준으로 정렬되며, 타겟 앱 해상도 외곽 영역은 시각적으로 음영(Dimmed) 처리되어 실제 감지 영역만 집중할 수 있습니다.
- **🔍 정밀 돋보기 (Loupe HUD)**: 마우스 커서 주변 11×11 픽셀 격자를 확대 표시하며, 정확한 상대 좌표와 RGB / HEX 값을 실시간 제공합니다.
- **⚠️ 조건 고유화 및 중복 감지**:
  - 서로 다른 레퍼런스 이미지로 프리셋을 생성했더라도 결과적으로 동일한 좌표와 색상 조건이 만들어진 경우, **경고 배지(⚠️)와 툴팁**으로 중복 여부를 즉시 가시화합니다.

### 3. 🧠 실행 조건 및 분기 처리 (Brain)
- 컬러 피커가 읽은 색상을 기준값과 실시간 비교 (허용 오차 0~255 및 일치/불일치 모드 지원).
- 논리 연산자:
  - `AND`: 등록된 모든 포인트가 일치해야 실행
  - `OR`: 등록된 포인트 중 하나 이상 일치 시 실행
- 분기 처리:
  - **조건 일치 시 (On Match)**: 액션 실행 후 다음 단계 / 특정 시나리오로 점프 (Jump) / 실행 정지 (Stop)
  - **조건 불일치 시 (On Mismatch)**: 다음 단계 진행 / 특정 시나리오로 점프 (Jump) / 재시도 (최대 N회, 간격 지정) / 실행 정지 (Stop)

### 4. ✋ 액션 시퀀스 (Hand)
- **마우스**: 좌클릭, 우클릭, 휠클릭, 단일/더블클릭, 반복 횟수 설정
- **드래그 앤 드롭**: 시작 상대좌표 → 종료 상대좌표, 드래그 이동 시간(ms) 설정
- **키보드**: 단일 키(Enter, Space, Esc, F1~F12 등) 및 조합키(Ctrl, Alt, Shift)
- **텍스트 입력**: 문자열 자동 타이핑
- **대기 (Delay)**: N초 정밀 대기 (예: 3초 대기)
- **유틸리티**: 비프 사운드 알림, 사용자 커스텀 로그 기록

### 5. 📊 스프레드시트 리스트 UI
- **상하로 시원하게 긴 창 (Tall Vertical Layout)** 구조로 다수의 시나리오 단계를 한눈에 파악.
- 엑셀/스프레드시트처럼 정돈된 그리드에서 시나리오 순서(#), 활성 On/Off, 고유 ID, 이름, 조건 요약, 분기 처리, 액션 요약을 직관적으로 확인 및 수정.

## 🚀 빠른 시작 (실행 방법)

### 요구 사양
- OS: Windows 10 / 11 (64-bit)
- Python 3.10+ (PyQt5, Pillow, mss, pywin32, numpy)

### 실행
`FGOA` 폴더에서 `run.bat` 파일을 더블 클릭하거나 콘솔에서 실행합니다:

```powershell
# 프로젝트 폴더로 이동 후 실행
cd C:\Users\demo_\Documents\GitHub\FGOA
.\run.bat
```

직접 Python으로 실행하는 경우:
```powershell
python main.py
```

## ⌨️ 단축키 안내

| 단축키 | 기능 |
|---|---|
| `F5` | 시나리오 실행 시작 / 일시정지 해제 |
| `F6` | 즉시 실행 정지 (Emergency Stop) |
| `F7` | 단일 스텝 전진 (디버깅 모드) |
