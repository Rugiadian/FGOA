# FGOA (지능형 윈도우 오토 조작 툴)

> **정형화된 매크로를 넘어, 화면의 시각적 변화(색상)를 실시간으로 감지하여 유연하게 대처하는 지능형 윈도우 자동 입력 툴**

---

## 📌 4대 핵심 기능 (Eye - Brain - Hand - Pivot)

### 1. 👁️ 포인트 읽기 (컬러 피커 - Eye)
- **점(Point) 모드**: 지정한 단일 좌표의 RGB 색상을 추출
- **선(Line) 모드**: 시작점과 끝점 사이의 선을 5분할하여 다중 샘플링, 화면 내 이동/변화 감지
- **9배율 돋보기 HUD**: 컬러 피커 실행 시 마우스 커서 주변을 9배율로 확대하여 픽셀 단위로 정밀하게 조준 가능
- **오차 허용치(Tolerance)**: 미세한 렌더링 차이나 안티에일리어싱에도 견고하게 판정 (RGB 거리 기반 오차 감지)

### 2. 🧠 실행 조건 및 판단 흐름 (Brain)
- 컬러 피커가 실시간으로 읽은 색상을 기준값과 비교
- **일치(Match) 시 분기**:
  - `액션 시퀀스 실행`: 등록된 마우스/키보드 입력 수행
  - `다른 시나리오(#No)로 점프`: 워크플로우 분기 (예: 전투 승리 화면 감지 시 시나리오 #5로 전환)
  - `매크로 정지`: 조건 충족 시 안전하게 자동화 종료
  - `일시 중지(대기)`: 특정 시간 대기 후 재확인
- **불일치(Mismatch) 시 분기**:
  - `다음 시나리오로 계속 진행`
  - `특정 시나리오(#No)로 점프` (예: 로딩 화면 미완료 시 재시도 루프)
  - `매크로 정지`

### 3. 🖐️ 액션 입력 재생 (Hand)
- **클릭 계열**: 좌클릭, 더블클릭, 우클릭 (지정 좌표 또는 현재 위치)
- **스무스 드래그(Drag)**: 시작점부터 끝점까지 사람 손처럼 자연스러운 `EaseInOut` 보간 곡선 이동 및 홀드 지원
- **키보드 제어**: 단일 키 누름/단축키 조합
- **텍스트 타이핑**: 클립보드 방식 및 키 입력 시뮬레이션
- **시나리오 점프 액션**: 액션 시퀀스 중간에서도 지정 번호 시나리오로 즉시 이동 가능
- **지연 시간(Delay)**: 밀리초 단위 정밀 대기

### 4. 🧭 좌표 피봇 (유연성)
- **창 상대 좌표 (Window Relative 0,0)**: 게임 창의 좌상단을 (0,0)으로 삼아, 창을 모니터 내 어디로 이동하더라도 오차 없이 클릭/색상 추출 수행
- **전체 화면 절대 좌표 (Screen Absolute 0,0)**: 주 모니터의 절대 (0,0) 좌표를 기준으로 동작
- 언제든 상단 피봇 스위치를 통해 원클릭 전환 가능

## ⚡ 핫키 (Hotkeys) 및 제어

| 단축키 | 기능 | 설명 |
|---|---|---|
| **ESC** | **전역 긴급 즉시 정지** | 어떤 작업 중이든 즉각 마우스/키보드 제어 및 매크로 엔진 정지 |
| **F6** | **매크로 시작** | 활성화된 시나리오 시퀀스 실행 시작 |
| **F7** | **매크로 정지** | 실행 중인 매크로 일반 정지 |

- **🔇 단축키 비활성화 버튼**: 상단 우측 [📌 항상 위] 버튼 바로 왼쪽에 위치한 `[⌨️ 단축키 활성/비활성]` 버튼을 눌러 ESC, F6, F7 단축키 입력을 원클릭으로 켜거나 끌 수 있습니다. (게임 중 ESC/F6/F7 키가 간섭되는 것을 완벽 방지)

## 🎯 게임 창 지정 및 좌표 정밀 매핑 안내

- **화면 클릭으로 게임 창 지정**:
  - 버튼을 누르면 마우스 커서 아래에 위치한 대상 창을 자동으로 감지합니다.
  - 투명 테두리 그림자 오차 없이 실제 창 외곽선(Cyan 사각형)이 실시간 하이라이트되며, 클릭 시 해당 게임 창이 즉시 타겟으로 고정됩니다.
  - 마우스 휠, 내부 렌더러 컨트롤 등의 자식 윈도우 대신 최상위 게임 창을 지능적으로 감지하여 좌표 어긋남이 발생하지 않습니다.
- **좌표 피봇**:
  - `창 상대좌표(0,0)`: 게임 창 내부의 렌더링 화면 좌상단을 (0,0)으로 삼아, 창을 어디로 이동하더라도 정확한 위치를 클릭하고 색상을 감지합니다.
  - `화면 절대좌표(0,0)`: 전체 모니터 화면의 절대 픽셀 좌표 기준.

## 🚀 빠른 실행 방법

1. `Run_GameAutoTool.bat` 파일을 더블클릭하여 실행합니다.
2. 상단에서 **[🎯 화면 클릭으로 게임 창 지정]** 버튼을 누른 후 대상 게임 창을 클릭합니다.
3. 원하는 시나리오를 구성하고 **[오토 시작 (F6)]** 버튼을 누릅니다.
4. 긴급 상황 발생 시 언제든지 키보드의 **[ESC]** 키를 누르면 즉시 멈춥니다.
